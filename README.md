# pi status logging

- `pi-status-logger.sh` is used to record the staus of pi with data like timestamp,cpu_temp,cpu_usage_percent,ram_used_mb,ram_total_mb,ram_percent,core_voltage,throttled_flags, 
- every two minutes a file will be created and the data will be recorded
- create a user group pilogs and add the current logged in user to that group 
    ```bash
    sudo groupadd pilogs
    sudo usermod -aG pilogs idks
    ```
- updated the permissions of the file `/var/log/pi-status-logger`
    ```bash
    sudo chown root:pilogs /var/log/pi-status-logger
    sudo chmod 770 /var/log/pi-status-logger
    ```
- the log of `pi-status-logger.sh` will be sotred in `/var/log/pi-status-logger/service.log`
- the script `pi-status-logger.sh` is made as a systemd service and it's config is in `/etc/systemd/system/pi-status-logger.service` and to make it as a system service run below commands
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable pi-status-logger.service
    sudo systemctl start pi-status-logger.service
    ```
- rotate the logs generated by the process `pi-status-logger.sh` (not the actual status of pi) using crontab, use the config `pi-status-logger-cron` and keep it in `/etc/logrotate.d/`
